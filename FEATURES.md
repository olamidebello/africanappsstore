# Requested capability coverage

| Requested area | Current implementation | Remaining work |
|---|---|---|
| Navigation/discovery | Apps, Games, Books, search, top charts, app pages | Editorial collections, promotions, recommendation engine, category/rating/device filters |
| App information | Name, package, developer, description, version, age, privacy link, downloads, APK hashes | Screenshots/video, verified compatibility, content rating authority, structured data safety, release editing |
| Downloads/updates | Authenticated APK transfer, release records, library | Native Android installer, update comparison, pause/retry, background delivery, archiving, storage management |
| Account | Registration/login/logout | Email verification, reset, MFA, federated login, account deletion/export |
| Social/trust | Reviews, replies, wishlist, reports | Helpful votes, review report queues, sorting/filtering, abuse handling |
| Developer console | Draft creation, APK upload, submission | Identity verification, team RBAC, staged rollouts, signing/key management, localization, app bundle processing |
| Administration | Approve/reject/suspend, report/ticket/audit visibility | Report/ticket resolution, identity checks, detailed policy workflow |
| Commerce/subscriptions | Not implemented | Provider integration, verified webhooks, entitlements, recurring billing, refunds, payouts/tax handling |
| Security scanning | ZIP/manifest presence and SHA-256 only | Signature verification, sandbox analysis, malware scanner, quarantine policy, signing continuity |
| Families/children | Not implemented | Supervised accounts, parental PIN/approvals, enforced ratings, family entitlements |
| Rewards/memberships | Not implemented | Points ledger, tiers, offers, subscription catalog |
| Multi-device | Not implemented | Android companion/device enrollment, authenticated command queues, user-approved installation |
| Games | Game catalog; beta/preregistration interest records | Achievements, leaderboards, saves, launch notifications and testing tracks |
| Settings | Saved preference records | Applying preferences, enforceable network/download/family settings |
| Books | Catalog metadata only | EPUB/PDF/audio ingestion, purchase entitlements and reader/player |
| Support | Ticket submission/history, admin visibility | Replies, routing, resolution and notifications |
| Analytics/automation | Download counts and publication audit | Revenue, retention, crash telemetry, publishing API and outbound notifications |

Google Play Protect, Play Points, Play Pass, Google account management and Google device synchronization are Google services. This independent store does not claim to implement or integrate those proprietary services. Browser software cannot silently install or uninstall Android applications.
